With managed warehouse, users can view traces stored in Unity Catalog in the MLflow UI without selecting a SQL warehouse. MLflow runs trace queries on a SQL warehouse that it creates in your workspace when your workspace supports it, and on serverless compute otherwise. Workspace admins can enable Managed Warehouse for MLflow on the Previews page. See Managed warehouse for MLflow traces.

The managed Microsoft Graph Logs connector is now available in Beta in Databricks Lakeflow Connect.

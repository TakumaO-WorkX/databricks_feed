Dashboard enhancements and bug fixes

September 03, 2026
  • Embedded dashboard filter APIs: In embedded dashboards, you can now set and retrieve filter values through APIs. See Control dashboard filters programmatically.
  • Ranked table calculations in /importBI: Importing reports from Power BI and Tableau with the /importBI Genie Code command now includes ranked table calculations.
  • Color mappings: In a dashboard's theme settings, you can assign a specific color to a value by name. Any visualization that colors by that value uses the assigned color across the dashboard, for both color by field and color by series. See Consistent colors across widgets.
  • Rich text for dynamic data references: You can now apply rich text formatting to dynamic data references in text widgets, widget titles, and descriptions.
  • Dashboard variable improvements: Enhancements to dashboard variables:
    • Multiple fields: Viewers can now add, remove, and swap multiple fields through a dashboard variable on a visualization, instead of switching one field at a time. See Use dashboard variables.
    • Source dataset for options: Dashboard variable options now show their source dataset as a subtitle. See Create a dashboard variable.
  • Metric view downloads respect display names: Downloads from a metric view now use the display names defined for its fields. See Local metric views.
  • Always-visible scrollbars on faceted charts: Scrollbars now stay visible on scrollable faceted charts.
  • Data attachments in Slack and Teams: Dashboard subscriptions delivered to Slack and Microsoft Teams can now include data attachments in CSV, TSV, or Excel format. See Data attachments.
  • Cross-dataset filtering through relationships (Public Preview): When datasets are connected by a relationship, filters, selections, and parameters applied to one dataset now automatically carry across to widgets built on the related datasets. See Create dashboard relationships.
  • Genie Code for dashboard authoring: New authoring capabilities and fixes for Genie Code:
    • Improved automatic widget layout: When Genie Code adds widgets to a dashboard, it now places them in available layout space automatically.
    • Smoother editing: Genie Code no longer appears to stall between edits, and multi-step edits apply with less delay between steps.

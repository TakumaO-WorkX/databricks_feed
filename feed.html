Expanded networking billing for OpenSharing SecureConnect

August 13, 2026

Databricks will be expanding networking billing for OpenSharing SecureConnect. Today, data providers are billed for data transfer (egress) when recipients access shared data through SecureConnect. Additional charge types and access scenarios, including charges billed to recipients, are planned.

The following table summarizes the planned charges, who is billed, and how each applies across access scenarios:

¹ Data transfer (egress) does not apply when the recipient is in the same region as the provider.

² Applies only if the provider configures private connectivity by attaching a network connectivity configuration (NCC) to the metastore.
³ Databricks does not bill this charge. If recipients on classic compute or open recipients reach storage over the public network, their own cloud provider might bill them for network address translation (NAT) directly.
⁴ Same-region serverless recipients read from storage directly rather than through the managed proxy.

For rates, see Data transfer and connectivity pricing, or contact your Databricks account team.

Dashboard enhancements and bug fixes
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011Ce2SYC2xGXFd9tgUpVKXk'}]
August 13, 2026
  • Remove duplicate subscribers: Dashboard authors can now remove duplicate subscribers from a dashboard schedule. See Manage scheduled dashboard updates and subscriptions.
  • Import BI filters fix: Fixed a bug where some filters were not created when importing Power BI and Tableau reports with Genie Code (/importBI). See Import BI files using Genie Code.
  • Reversed y-axis tooltip order fix: Fixed a bug where tooltips for line and area charts with a reversed y-axis listed their series in the wrong order.
  • Duplicate schedule emails fix: Fixed a bug where dashboard schedules could send duplicate emails to the same subscriber.
  • Pivot table None transform fix: Fixed a bug where the None transform on pivot table values produced empty values.

Genie Agents enhancements and bug fixes
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011Ce2SYDvZLhsaMLREBMGhz'}]
August 13, 2026
  • Content search for attached volumes (Beta): For better latency and accuracy when answering questions across larger volumes, you can now optionally enable content search on attached volumes. Content search indexes and prepares your files for the Genie Agent. See Enable content search for attached volumes.
  • Analyze files in volumes without Unity AI Gateway (Beta): Analyzing files in volumes no longer requires Unity AI Gateway to be enabled. See Analyze files in volumes with a Genie Agent.
  • Send a prompt with an uploaded file: Uploading a file to a conversation no longer automatically sends a message. You can now send a prompt along with the uploaded file. See Upload a file to a Genie Agent.
  • Conversation list API matches monitoring sources: The conversation list API now returns conversations from the public API, Genie One, and embedded Genie, so the conversations it returns match the history shown on the monitoring page. See Use the Genie Agents API.
  • Conversation timestamps in the API: The public Genie Agents API now returns create_time and update_time for a Genie space. GET requests to list or get spaces return the same last-modified information shown in the Genie Agent UI. See Use the Genie Agents API.
  • Metric view synonyms fix: Fixed a bug where synonyms defined in a metric view were not used as context for the agent.
  • Table access error message: Simplified the error message shown when a user does not have access to one or more tables attached to a Genie Agent.

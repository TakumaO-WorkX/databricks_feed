Maintenance windows for continuous pipelines
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011Cewi7t7qRxPCCrvaxqi6b'}]
September 10, 2026

You can now set a maintenance window on a continuous Lakeflow pipeline to control when Databricks applies platform updates that require a restart, such as new runtime versions and serverless infrastructure maintenance. Select a day of the week, a start hour, and a time zone, and Databricks starts maintenance only within that one-hour window. Configure the window in the Jobs UI, the Pipelines UI, or the Jobs REST API.

See Manage updates for continuous pipelines.

The Databricks Excel Add-in is now generally available
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011Cewi7uUhEmFFh8w7YXYSH'}]

The Databricks Excel Add-in is now generally available. Connect Microsoft Excel to your Databricks workspace to browse and import governed Unity Catalog tables and views, run SQL queries, build pivot tables, use custom functions, and write data back to Unity Catalog. You can now also enable Live query when building pivot tables to see results as you update the fields.

See Connect to Databricks from Microsoft Excel.

Genie Agents enhancements

  • Increased data source limit: Each Genie Agent supports up to 50 tables, views, or metric views as data sources, up from 30. See Technical requirements and limits.
  • Increased conversation limit: Each Genie Agent can store up to 200,000 conversations, up from 10,000. See Technical requirements and limits.

Dashboard enhancements
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011Cewi7xKLrn1CrxEJiAHHo'}]
September 10, 2026
  • More Tableau calculations in /importBI: Importing Tableau reports with the /importBI Genie Code command now supports more cases of parameterized calculations. See Import BI files using Genie Code.
  • Relationship-scoped filters (Public Preview): On a dashboard with relationships, each widget now responds only to filters whose dataset is related to it, so a filter no longer affects unrelated charts. See Dashboard relationships.
  • Choose the warehouse for materialization: When you export a dashboard dataset as a materialized view in Unity Catalog, you can now choose which SQL warehouse runs the materialization. See Export a dataset as a materialized view.
  • Include-style LOD expressions: The metric view editor now supports Include-style level of detail (LOD) expressions in YAML.
  • Scoped starter questions: On a published dashboard, Ask Genie's suggested starter questions are now scoped to the dashboard page and widget you're viewing.
  • Key insights per page: Key insights now generate for each dashboard page. A New insights badge appears only when new insights are available, along with a live-generating indicator.
  • Selected chart as Ask Genie context: On a published dashboard, the Ask Genie input bar now shows the chart you selected as context, so you can ask questions about that specific chart. See Ask Genie about a specific chart.
  • Metric view reuse when building: When building a dashboard, Genie Code now prefers governed metric views over ad-hoc SQL datasets and reuses an existing metric view when one satisfies the request. See Use Genie Code for dashboard authoring.
  • Export and import dashboard themes: You can now export a dashboard's theme to a JSON file and import a theme file into another dashboard, so you can reuse or share a theme without editing the dashboard JSON. See Export or import a theme.
  • Line shape control: Line and area charts now have a Line shape control that connects data points with linear, smooth, or stepped lines. See Line shape.
  • Color scale on pivot table text: The pivot table color scale now includes an Apply to setting, so you can paint the color gradient on the cell text as well as the background. See Value-level settings.
  • Path maps from point sequences: Path maps can now connect a sequence of ordered points into a line, from separate longitude and latitude columns or a single point geometry column, in addition to a single geometry line column. Use this for trajectories such as GPS tracks. See Path source.

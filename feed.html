Dashboard enhancements and bug fixes
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CfddqTGM9QWooMziaxdje'}]
October 01, 2026
  • Materialize SQL datasets (Beta): Dashboard materialization now covers SQL datasets in addition to local metric views, so you can materialize a dashboard's SQL datasets. See Dataset materialization in AI/BI dashboards.
  • Select multiple tables when adding a data source: You can now select multiple tables at the same time in the Add data source picker when building a dashboard data model.

    • Genie Code can now use images stored in your workspace as image widgets, not only uploaded files.
    • The dashboard canvas now stays visible while Genie Code builds datasets step by step, so you can watch widgets appear instead of seeing a blank screen.
    • Genie Code can now create dashboard materializations when you ask it to (Beta).

LTAP Direct Writes is generally available
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CfddqUPa5gm6TTnHcguJV'}]
October 01, 2026

LTAP Direct Writes is now generally available. It speeds up how synced tables load into Lakebase by writing the initial load and full refreshes directly to the storage layer instead of through your compute endpoint, so large loads finish faster without competing with your queries. You opt in per synced table by selecting LTAP Direct Writes under Synchronization settings when you create the synced table. It's supported on Lakebase projects running Postgres 16, 17, or 18. See Accelerated sync with LTAP Direct Writes.

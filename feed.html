Dashboard enhancements and bug fixes
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CfAyW4FwR4SPbcGLD5cUR'}]
September 17, 2026
  • Convert a SQL dataset to a local metric view: You can now convert a SQL dataset into a local metric view from the dataset's context menu, and Genie Code handles the conversion. See Local metric views and Use Genie Code for dashboard authoring.
  • SQL dataset parameters in Genie Code: Genie Code for dashboard authoring now understands SQL dataset parameters when building and editing dashboards. See Use Genie Code for dashboard authoring.
  • Reference aggregated field values in widget titles and descriptions: Type @ in a visualization widget's title or description to insert a field reference. The reference shows a live, formatted metric, such as a sum or an average, that responds to the dashboard's filters. Click the reference to change the field, aggregation function, and number or date formatting. See Reference a filter or field.
  • Default expand level for pivot tables: You can now set the number of row and column hierarchy levels a pivot table expands to when it first loads. See Set the default expand level.
  • Independent axis scaling on faceted charts: You can now scale a numeric axis to each subchart's own data on a faceted chart instead of sharing one range across subcharts. Set the axis range to Per facet. See Faceting.
  • Theme picker previews: The preset theme picker now shows a color palette preview for each theme before you select it.
  • Reorder field variable options: You can now reorder the options in a field variable.
  • Style pivot table totals: You can now style the headers and values of a pivot table's totals independently, and apply conditional styling to them. See Style pivot table totals.
  • Dashboard variable undo and redo fix: Fixed a bug where undo and redo did not apply to dashboard variables.

Metastore-level ABAC policies are in Beta
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CfAyW8HXscu6mgyT6dVYp'}]
September 17, 2026

Metastore-level ABAC policies are in Beta in Unity Catalog. You can now attach an ABAC policy (row filter, column mask, GRANT, or DENY) at the metastore level, so a single policy applies across every catalog in the metastore, including catalogs created later. This gives governance teams one place to enforce organization-wide data protection rules without replicating a policy for each catalog.

For details, see Metastore-level ABAC policies (Beta).

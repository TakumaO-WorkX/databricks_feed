OpenAI connector (Beta)
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CdfoUNEsgKJiUVPFMVX8F'}]
July 31, 2026

The OpenAI connector is now available in Lakeflow Connect in Beta. Workspace admins can control access to this feature from the Previews page.

The connector uses the OpenAI Organization Admin API to ingest organization administration data, such as users, projects, API keys, usage, costs, and audit logs, from OpenAI into Databricks. Authentication uses an OpenAI Admin API key.

See OpenAI connector.

Dashboard enhancements and bug fixes
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CdfoUPAgcS1QwrARjQZM1'}]
July 30, 2026

  • Dashboard relationships from imported BI files: When you import a Power BI or Tableau file with Genie Code, migration tooling now creates dashboard relationships where it detects them in the source file. See Import BI files using Genie Code.

  • Customize date picker quick-select options with Genie Code: You can now ask Genie Code for dashboard authoring to customize the quick-select options in a date range picker filter, such as keeping only day-based ranges. For an example prompt, see Optional: Customize the date picker quick-select options with Genie Code.

  • Full undo and redo in Genie Code: Genie Code for dashboard authoring now supports full undo and redo. Each Genie Code response is a single step that you can undo as a unit, including restoring an emptied dashboard. See Use Genie Code for dashboard authoring.

  • Semantic validation for AI-authored metrics: Genie Code for dashboard authoring now automatically runs a semantic validation check after it creates a widget. The check validates business definitions, grain, attribution, population, time window, units, scale, and category values to improve the accuracy and consistency of metrics.

  • Low-code filters on measures: Local metric views now provide a low-code option for adding filters to measures. See Step 3: Define a filter.

  • Improved low-code UI for imported metric views: Metric views imported from Unity Catalog now use an improved low-code UI for extensions and modifications. See Extend a Unity Catalog metric view.

  • Metric view display names on dashboard widgets: Dashboard widgets now show the display name defined for each field in a local metric view instead of the literal field name. See Local metric views.

  • Cross-filtering includes the facet field: Cross-filtering on a faceted chart now includes the facet field as part of the filter. See Apply cross-filtering.

  • Applied filters in email attachments: Dashboard authors can now include the applied filters as a separate tabular attachment in email subscriptions. See Email attachments.

  • Warehouse picker for full-page Genie Code: The warehouse picker now appears for full-page Genie Code. See Full page Genie Code.

  • Dark mode scrollbar fix: Fixed a bug where the filter drop-down scrollbar did not appear in dark mode.

  • Line chart tooltip fix: Fixed a bug where tooltips did not appear on line charts.

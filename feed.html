OAuth authentication for webhook destinations will soon be available by default for workspaces with the compliance security profile enabled
> [翻訳エラー: Error code: 404 - {'type': 'error', 'error': {'type': 'not_found_error', 'message': 'model: claude-3-haiku-20240307'}, 'request_id': 'req_011ChDv2K138sfnquR3QRYr6'}]
November 20, 2026

Starting on or after December 20, 2026, OAuth authentication for webhook destinations will be available by default for workspaces with the compliance security profile enabled, subject to the requirements for regions and compliance standards.

Use OAuth 2.0 client credentials to send notifications to an endpoint that requires an access token. Databricks obtains the token from the configured OAuth token endpoint and uses it to authenticate the notification request. Existing webhook destinations retain their configured authentication.

See OAuth authentication for webhook destinations.

Beginning September 2026, public S3 links for downloading the Simba JDBC Driver (Legacy) will be disabled. After this date, scripts or processes that use direct public links to download the driver will no longer function. In addition, downloading from the JDBC archive page will require signing in to Databricks.

To continue using automated downloads, migrate to the Databricks JDBC Driver before September 2026. See Databricks JDBC Driver.

Lakeflow Designer Summer Release
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CdSYmeNQkFCLoFWmxfxZA'}]
July 24, 2026

The Lakeflow Designer Summer Release adds new operators, expands the Output and Join operators, and improves the canvas editing experience. The following updates are now available:

  • Prepare operator: Use the new Prepare operator for common data-cleansing tasks, including changing text case and data types, replacing values, and applying formulas. See Prepare.
  • Enter Data operator: Manually create tabular data in a spreadsheet-style editor. See Enter Data.
  • Select operator: Use the new Select operator to choose which columns to keep, rename columns, and reorder them in the output. See Select.
  • Visualization operator: Create and view visualizations directly on the canvas. See Visualization.
  • Improved Output operator: The Output operator now supports inserting or appending data in Unity Catalog tables, publishing results as materialized views, and writing CSV, Excel, or JSON files to Unity Catalog volumes. See Output.
  • Split Join outputs: The Join operator now provides three outputs by default: unmatched left rows, matched rows, and unmatched right rows. This makes it easier to branch a workflow based on join results. See Join.
  • Case-sensitive joins: The Join operator now includes a Match case option and matches string keys case-insensitively by default.
  • Matched and unmatched Filter outputs: The Filter operator now provides separate outputs for matching and non-matching rows, so you can branch data based on whether it meets the filter conditions. See Filter.
  • Improved date filtering: The Filter operator's date picker now supports navigating across years as well as months.
  • Additional AI functions: The AI Function operator now supports ai_query, ai_parse_document, ai_forecast, and ai_prep_search. See AI Function.
  • Folder and volume inputs: The Source operator can now target an entire Unity Catalog volume or folder path instead of an individual file. See Source.
  • Metric view sources: Use Unity Catalog metric views as source nodes in Lakeflow Designer. See Source.
  • Inline Note editing: The Note operator now supports inline rich-text editing directly on the canvas, including headings, text styling, links, images, and tables. See Note.
  • Easier node connections: Redesigned node ports provide larger connection targets and clearer visual cues, making operators easier to connect.
  • Clearer operator configuration cues: Unconfigured operators now have a dashed border, and required input ports that aren't connected are highlighted in yellow.
  • Table of contents panel: Find and navigate to any operator using the new searchable table of contents in the left sidebar. Select an operator to focus it on the canvas, then expand the Generated code section to view its underlying code.
  • Command palette: Press Cmd+Shift+P on macOS or Ctrl+Shift+P on Windows to quickly access editor actions.
  • Visual data prep listing page: Find all of your visual data prep files from a dedicated Visual data prep page in the sidebar. The page includes a getting-started video banner to help you start using Lakeflow Designer.
  • Improved caching: On all-purpose compute, downstream operators can reuse cached upstream results, reducing repeated work for long-running steps such as AI functions.
  • Large-canvas performance: Scrolling and panning are more responsive on canvases with more than 200 operators.
  • Serverless environment selection: When working with visual data prep files, you can now choose the serverless environment used for both interactive runs and scheduled jobs.
  • Improved scheduled-job readability: Scheduled visual data prep runs now display each operator as an individual node in the Jobs task graph instead of showing raw Python code.
  • Declarative Automation Bundles support: Deploy and run visual data prep files with Declarative Automation Bundles by configuring them as notebook tasks and referencing the file path in notebook_task.notebook_path. See Move a visual data prep file to production.

Git CLI commands in Git folders are now in Public Preview
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CdSYmgMin3a3Kvf5bbZE4'}]
July 24, 2026

Git CLI commands in Git folders are now in Public Preview. Git folders that you create from the UI automatically get Git CLI access when your workspace is eligible, so you can run standard Git commands such as git stash, interactive rebase, pre-commit hooks, Git submodules, and Large File Storage (LFS) directly from a Databricks terminal. Workspace admins can control access to this feature from the Previews page. See Use Git CLI commands.

Genie Agents enhancements
> [翻訳エラー: Error code: 404 - {'type': 'error', 'error': {'type': 'not_found_error', 'message': 'model: claude-3-haiku-20240307'}, 'request_id': 'req_011CgmzoPrMZ5wjjjg13LQGg'}]
November 05, 2026
  • Answers from accessible sources: Users who can access only some of the volumes or MCP connections attached to a Genie Agent are no longer blocked from using it. The agent answers using only the sources that the user can access. See Manage data objects.
  • Custom claims in the Monitor tab: For Genie Agents that an app queries with an OAuth custom identity claim, the Monitor tab can now show each message's claim, so you can tell which of the app's end users asked it. Turn on the Custom claim column from the column picker. See Monitor the agent.
  • Faster benchmark runs: Benchmark questions now run in parallel, so benchmark evaluations finish sooner. See Benchmarks.

Genie One enhancements
> [翻訳エラー: Error code: 404 - {'type': 'error', 'error': {'type': 'not_found_error', 'message': 'model: claude-3-haiku-20240307'}, 'request_id': 'req_011CgmzoQsspPqPr4VQq2DXN'}]
November 05, 2026
  • Genie traces in the unified trace table (Beta): Genie Code and Genie One turns can now be exported to the Unity Gateway unified trace table as OpenTelemetry spans. A workspace admin turns on tracing for each product from the Previews page. By default, only the trace table's owner can query the traces. See Monitor Genie Code and Genie One with the unified trace table.
  • Faster responses: Genie One now responds more quickly when you ask a question.
  • Expand visualizations: You can now open a visualization from a Genie One response in the side panel, where you can interact with it at a larger size next to the conversation. See Expand a visualization.

Dashboard enhancements and bug fixes
> [翻訳エラー: Error code: 404 - {'type': 'error', 'error': {'type': 'not_found_error', 'message': 'model: claude-3-haiku-20240307'}, 'request_id': 'req_011CgmzoRw8D1upaecXDQEPp'}]
November 05, 2026
  • Reorder dashboard variables: Authors can now reorder dashboard variables directly in the dashboard editor. See Use dashboard variables.
  • Display names for field variable options: Authors can now set a display name for each option in a field variable, such as Total revenue instead of Sum of sales. You can also ask Genie Code to set, rename, or clear these display names, and it keeps the names you set when it edits the variable. See Set display names for field options.
  • Import relationships from Unity Catalog with Genie Code (Beta): Genie Code for dashboard authoring can now import the relationships declared on Unity Catalog metric views into a dashboard as dashboard relationships. See Use relationships with Genie Code for dashboard authoring.
  • Waterfall chart labels: Labels on waterfall charts now stay visible when they're close to the top or bottom of the axis.

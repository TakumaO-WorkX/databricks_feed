November 09, 2026

When you create new jobs compute in the UI, the access mode now defaults to Auto instead of Dedicated. Auto uses Standard access mode unless a machine learning runtime, a GPU instance type, or a Databricks Runtime version lower than 14.3 is selected. A cluster policy that enforces a different access mode still takes precedence. Existing jobs are not changed.

For workspaces with the compliance security profile enabled, this change takes effect in December 2026. See What's coming.

See Use standard access mode.

Artifacts and slides in Genie One (Beta)
> [翻訳エラー: Error code: 404 - {'type': 'error', 'error': {'type': 'not_found_error', 'message': 'model: claude-3-haiku-20240307'}, 'request_id': 'req_011Ch1H5wMYW1REJCYvQ8fQ9'}]
November 12, 2026

Artifacts are slide decks and other custom visual pages that Genie One builds from your data and saves to your workspace. Ask Genie for an artifact in chat, edit it yourself or ask for changes, then present it and share it with others. Anyone who views an artifact can use Ask Genie to ask questions about the data behind a chart or number. An artifact stores a snapshot of its data, so anyone who can view it sees that data, even without access to the source tables. This feature is in Beta. A workspace admin turns on the Artifacts preview from the Previews page. See Artifacts in Genie One and Slides in Genie One.

Dashboard enhancements and bug fixes
> [翻訳エラー: Error code: 404 - {'type': 'error', 'error': {'type': 'not_found_error', 'message': 'model: claude-3-haiku-20240307'}, 'request_id': 'req_011Ch1H5yCv1YHrFapkNCsSn'}]
November 12, 2026
  • Custom calculations with Genie Code: Genie Code can now write custom calculations that reference other custom calculations in the same dataset. See Referencing other calculations.
  • Sort pivot tables: Viewers can now sort pivot tables by row and column. See Table and pivot table visualizations.
  • Pivot table header styles: Authors can now style pivot table headers separately for each row, column, and value field. See Style pivot table headers.
  • Pivot table text wrapping: Pivot table values can now adjust their height to wrap text.
  • Pivot table divider: Authors can now resize the divider between columns and values in a pivot table.
  • Associative filtering: Authors can now turn off associative filtering between dashboard filters. See Configure filter application behavior.
  • Undo and redo for dashboard variables: Actions on dashboard variables now support undo and redo. See Use dashboard variables.
  • Ask Genie on supported widgets: Ask Genie now appears only on widgets that Genie can use as context. It no longer appears on images, filters, or older text boxes.
  • Waterfall chart axis: The y-axis on waterfall charts now extends so data labels aren't cut off.

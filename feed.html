August 06, 2026
  • Rich text in widget titles and descriptions: Visualization widget titles and descriptions now support rich text formatting. Click a widget's title or description to open a formatting toolbar, where you can apply text styling, links, and tables, or enter Markdown text directly. See Format widget titles and descriptions.
  • Hide pivot table column headers: Dashboard authors can now hide the column header in a pivot table. See Value-level settings.
  • Schedule run history: Dashboard authors can now see the run history for a schedule, including the run ID, start and end times, and status for each of the five most recent runs. See View schedule run history.

Genie Agents enhancements and bug fixes
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CdoBz2eaQwA7Ji7SmvLZ4'}]
August 06, 2026
  • Markdown tables in Agent mode APIs (Beta): In the Agent mode APIs, table visualizations now return as markdown instead of table visualization attachments, which improves readability. See Parse the report.
  • Longer agent descriptions: Genie Agents now show more of an agent's description by default, so you can see the purpose of each agent at a glance.
  • Comment on answers from Genie One: You can now add text comments to Genie Agent answers from Genie One.
  • Conversation mode in list APIs: The list conversations APIs now include a field that indicates whether a conversation was sent in Agent mode or Chat mode.
  • Download CSV in embedded agents: In embedded Genie Agents, download CSV actions now run inside the iframe instead of sending you to a separate page.
  • Agent thumbnail fix: Fixed a bug where Genie Agent thumbnails appeared too small in Genie One.
  • Agent mode benchmark results fix: Fixed a bug where agent mode benchmark results appeared as chat mode results.
  • Benchmark error messages: Benchmark runs now show a descriptive error message when a transient issue interrupts a run. Previously, these runs returned empty results with no explanation.

Databricks-managed MCP connectors are now integrated with Unity AI Gateway (Beta)
> [翻訳エラー: Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message': 'Your credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.'}, 'request_id': 'req_011CdoBz5E7E12nGSLd8wAXu'}]
August 06, 2026

All Databricks-managed MCP connectors for Genie One and Genie Code have migrated to the Unity AI Gateway. This brings Databricks-managed connectors under Unity AI Gateway, enabling centralized governance, access controls, and visibility alongside your other MCP servers and tools.

Users must reauthenticate their connectors to continue using them with Genie One and Genie Code. A notification in Genie prompts impacted users to reconnect.
